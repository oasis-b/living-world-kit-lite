Explain this map of the RPG Maker project: $ARGUMENTS

1. Use the rpg-maker-helper skill. Find the map in MapInfos.json (by id or name) and read its file.
2. Give a short overview: size, display name, tileset, music, encounters, notes.
3. Draw a small text grid of the map with the events at their positions and the exits marked.
4. List the exits: every Transfer Player on this map and where it leads, and every transfer on other maps that leads here.
5. Go through the events in a sensible order (story first, then people, then the rest). For each: id, name, position, what each page does in one or two sentences, and what makes the next page active.
6. End with anything that looks wrong, each with the fix as clicks in the editor.
